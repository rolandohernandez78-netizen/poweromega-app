# PowerOmega APP

Aplicación web para la estimación morfométrica del peso equino, evaluación de
condición corporal y orientación nutricional con EQUIGRAS®.

## Publicación

La rama `main` se publica automáticamente mediante Netlify.

- Sitio: https://poweromega-app.netlify.app/
- Directorio de publicación: raíz del repositorio

## Flujo de actualización

1. Modificar y validar los archivos locales.
2. Crear un commit con los cambios.
3. Enviar el commit a la rama `main` de GitHub.
4. Netlify detectará el cambio y publicará una nueva versión.
